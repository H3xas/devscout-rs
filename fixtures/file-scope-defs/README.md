# File scope declaration fixtures

`mixed` combines exported and local declarations. `kinds` covers declaration kinds, destructuring, and require bindings. `iife` covers direct and assigned wrappers, nested wrappers, and excluded positions. `refs` covers calls, constructors, JSX, and dispatch. `cross` covers import and re-export boundaries. `cjs-barrel` and `require-exports` cover require bindings exported through CommonJS, ESM and default-export forms. `ties` covers name ambiguity and member fallback. `components` covers four exported and file-local React component shapes in `.tsx` files, with their JSX uses in an importing file. `default-imports` covers a file-local declaration named by a statement-form default export and an exported declaration named by a clause-form default export. It reaches both through direct imports, barrels, namespace members and access by the local name. `userscript` covers script wrappers with namespace assignments.
