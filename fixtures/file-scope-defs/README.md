# File scope declaration fixtures

`mixed` combines exported and local declarations. `kinds` covers declaration kinds, destructuring, and require bindings. `iife` covers direct and assigned wrappers, nested wrappers, and excluded positions. `refs` covers calls, constructors, JSX, and dispatch. `cross` covers import and re-export boundaries. `ties` covers name ambiguity and member fallback. `userscript` covers script wrappers with namespace assignments.
